# First Steps

Get up and running with ServicePro.

## Setup Checklist

### Day 1: Account Setup

- [ ] Log in and change password
- [ ] Set up company profile
- [ ] Upload company logo
- [ ] Configure business hours
- [ ] Set time zone

### Day 2: Team Setup

- [ ] Invite team members
- [ ] Assign roles and permissions
- [ ] Configure notification preferences

### Day 3: Customer Data

- [ ] Add first customers manually
- [ ] Import existing customers (CSV)
- [ ] Set up customer types

### Day 4: Job Configuration

- [ ] Create job types
- [ ] Set default durations
- [ ] Configure pricing

### Day 5: Billing Setup

- [ ] Configure invoice settings
- [ ] Connect payment processing (Stripe)
- [ ] Create invoice templates

## Company Profile Setup

1. Go to **Settings > Company Profile**
2. Fill in:
   - Company name
   - Address
   - Phone and email
   - Tax ID
3. Upload logo (PNG or JPG)
4. Save changes

## Invite Your Team

1. Go to **Settings > Team**
2. Click **+ Invite User**
3. Enter email and role:

| Role       | Access                |
| ---------- | --------------------- |
| Admin      | Full access           |
| Manager    | Team and operations   |
| Dispatcher | Scheduling only       |
| Technician | Assigned jobs only    |
| Billing    | Invoices and payments |

## Add Your First Customer

1. Click **Customers > + Add Customer**
2. Enter:
   - Name and type
   - Contact info
   - Service address
3. Save

## Schedule Your First Job

1. Click **Jobs > + New Job**
2. Select customer
3. Choose job type
4. Pick date and time
5. Assign technician
6. Save

## Tips for Success

- Start with a few customers to learn the system
- Use the calendar daily to manage operations
- Set up recurring jobs for regular customers
- Enable payment reminders for faster collection
