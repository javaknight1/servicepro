# Glossary

Common terms used in ServicePro.

## General

| Term                | Definition                                 |
| ------------------- | ------------------------------------------ |
| **Customer**        | A person or company that receives services |
| **Contact**         | A person associated with a customer        |
| **Service Address** | Location where work is performed           |
| **Billing Address** | Address for invoices and statements        |

## Jobs

| Term              | Definition                                          |
| ----------------- | --------------------------------------------------- |
| **Job**           | A scheduled service visit or work order             |
| **Job Type**      | Category of work (Service Call, Installation, etc.) |
| **Dispatch**      | Sending a job assignment to a technician            |
| **Technician**    | Team member who performs the service                |
| **Recurring Job** | Job that repeats on a schedule                      |

## Job Statuses

| Status          | Meaning                      |
| --------------- | ---------------------------- |
| **Scheduled**   | Job is on the calendar       |
| **Dispatched**  | Technician has been notified |
| **In Progress** | Work is underway             |
| **Completed**   | Job is finished              |
| **Cancelled**   | Job was cancelled            |

## Quotes & Invoices

| Term              | Definition                                       |
| ----------------- | ------------------------------------------------ |
| **Quote**         | Estimate provided before work begins             |
| **Invoice**       | Bill for services rendered                       |
| **Line Item**     | Individual service or product on a quote/invoice |
| **Payment Terms** | Due date terms (Net 15, Net 30, etc.)            |
| **Credit**        | Amount applied to reduce balance                 |

## Quote Statuses

| Status       | Meaning                     |
| ------------ | --------------------------- |
| **Draft**    | Not yet sent to customer    |
| **Sent**     | Emailed to customer         |
| **Accepted** | Customer approved the quote |
| **Declined** | Customer rejected the quote |
| **Expired**  | Quote past expiration date  |

## Invoice Statuses

| Status      | Meaning                   |
| ----------- | ------------------------- |
| **Draft**   | Not yet sent              |
| **Sent**    | Emailed to customer       |
| **Viewed**  | Customer opened the email |
| **Paid**    | Full payment received     |
| **Partial** | Partial payment received  |
| **Overdue** | Past the due date         |

## Team & Permissions

| Term           | Definition                          |
| -------------- | ----------------------------------- |
| **Admin**      | Full access to all features         |
| **Manager**    | Can manage team and operations      |
| **Dispatcher** | Can schedule and assign jobs        |
| **Technician** | Can view and complete assigned jobs |
| **RBAC**       | Role-Based Access Control           |

## Calendar

| Term             | Definition                      |
| ---------------- | ------------------------------- |
| **Time Block**   | Reserved time on the calendar   |
| **Buffer Time**  | Gap between scheduled jobs      |
| **Conflict**     | Overlapping schedules           |
| **Availability** | Times when technicians can work |
