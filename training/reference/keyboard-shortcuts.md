# Keyboard Shortcuts

Quick reference for ServicePro keyboard shortcuts.

## Global Navigation

| Shortcut     | Action                  |
| ------------ | ----------------------- |
| `G` then `D` | Go to Dashboard         |
| `G` then `C` | Go to Customers         |
| `G` then `J` | Go to Jobs              |
| `G` then `Q` | Go to Quotes            |
| `G` then `I` | Go to Invoices          |
| `G` then `K` | Go to Calendar          |
| `G` then `R` | Go to Reports           |
| `G` then `S` | Go to Settings          |
| `/`          | Open global search      |
| `?`          | Show keyboard shortcuts |
| `Esc`        | Close modal / Cancel    |

## Calendar

| Shortcut     | Action               |
| ------------ | -------------------- |
| `D`          | Day view             |
| `W`          | Week view            |
| `M`          | Month view           |
| `T`          | Go to today          |
| `Left/Right` | Previous/Next period |
| `N`          | New job              |
| `E`          | Edit selected job    |

## Lists & Tables

| Shortcut       | Action             |
| -------------- | ------------------ |
| `Up/Down`      | Navigate rows      |
| `Enter`        | Open selected item |
| `Space`        | Toggle checkbox    |
| `Ctrl/Cmd + A` | Select all         |
| `Ctrl/Cmd + F` | Find in list       |
| `F`            | Toggle filters     |
| `R`            | Refresh            |

## Forms

| Shortcut           | Action         |
| ------------------ | -------------- |
| `Tab`              | Next field     |
| `Shift + Tab`      | Previous field |
| `Ctrl/Cmd + S`     | Save           |
| `Ctrl/Cmd + Enter` | Save and close |
| `Ctrl/Cmd + Z`     | Undo           |
| `Esc`              | Cancel         |

## Quick Actions

| Shortcut       | Action                  |
| -------------- | ----------------------- |
| `Ctrl/Cmd + N` | New (context-sensitive) |
| `Ctrl/Cmd + E` | Edit current            |
| `Ctrl/Cmd + D` | Duplicate               |
| `Ctrl/Cmd + P` | Print/Preview           |

## Search Operators

| Operator  | Example              | Description  |
| --------- | -------------------- | ------------ |
| `"exact"` | `"John Smith"`       | Exact phrase |
| `field:`  | `status:pending`     | Search field |
| `OR`      | `plumbing OR hvac`   | Match either |
| `-`       | `customer -inactive` | Exclude      |
| `>` `<`   | `amount:>500`        | Numeric      |
