# Troubleshooting

Common issues and solutions.

## Login Issues

### Forgot Password

1. Go to login page
2. Click **Forgot Password**
3. Enter your email
4. Check inbox for reset link
5. Create new password

### Account Locked

After 5 failed attempts, account locks for 30 minutes.

- Wait 30 minutes, or
- Contact support to unlock immediately

### Two-Factor Authentication Issues

- **Lost phone**: Use backup codes (provided at setup)
- **No backup codes**: Contact support with ID verification

## Email Problems

### Not Receiving Emails

1. Check spam/junk folder
2. Add noreply@servicepro.com to contacts
3. Verify email address in profile
4. Check email server isn't blocking

### Invoice Not Delivered

1. Verify customer email is correct
2. Check invoice status (Sent vs Draft)
3. Resend invoice from invoice detail page
4. Ask customer to check spam

## Calendar & Scheduling

### Jobs Not Showing

1. Check date range filter
2. Verify job status isn't Cancelled
3. Clear browser cache
4. Try different calendar view

### Time Zone Issues

1. Go to **Settings > Regional**
2. Verify correct time zone
3. Save changes
4. Refresh calendar

### Scheduling Conflicts

Conflict detection warns when:

- Technician already assigned at that time
- Customer has another job scheduled
- Outside business hours

## Payment Issues

### Payment Not Processing

1. Verify Stripe integration is active
2. Check customer card details
3. Review Stripe dashboard for errors
4. Try different payment method

### Wrong Amount Charged

1. Open invoice
2. Issue partial refund if needed
3. Contact support for full reversal

## Performance

### Slow Loading

1. Clear browser cache
2. Try different browser
3. Check internet connection
4. Disable browser extensions

### App Not Responding

1. Refresh the page (F5 or Cmd+R)
2. Clear cache and cookies
3. Try incognito/private window
4. Contact support if persistent

## Common Error Messages

| Error             | Solution                           |
| ----------------- | ---------------------------------- |
| Session expired   | Log in again                       |
| Permission denied | Contact admin for access           |
| Record not found  | May have been deleted              |
| Validation error  | Check required fields              |
| Server error      | Wait and retry, or contact support |

## Contact Support

If issues persist:

- **Email**: support@servicepro.com
- **Chat**: Click chat icon (bottom right)
- **Phone**: 1-800-SERVICE

Include in your request:

- What you were trying to do
- Error message (if any)
- Browser and device type
- Screenshots if possible
