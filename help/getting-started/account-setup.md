# Account Setup

Complete your ServicePro configuration.

## Configuration Checklist

- [ ] Company profile and branding
- [ ] Business hours and time zone
- [ ] Notification preferences
- [ ] Default job and invoice settings
- [ ] Team member invitations

## Company Profile

**Settings > Company Profile**

| Field        | Description                       |
| ------------ | --------------------------------- |
| Company Name | Legal business name               |
| Address      | Primary business address          |
| Phone        | Main business line                |
| Email        | Primary contact email             |
| Logo         | Upload PNG or JPG (min 200x200px) |
| Tax ID       | EIN or Tax ID                     |

## Business Hours

**Settings > Business Hours**

Set open/close times for each day. Configure:

- After-hours rate (e.g., 1.5x)
- Emergency availability
- Auto-response for after hours

## Time Zone & Locale

**Settings > Regional**

| Setting     | Description              |
| ----------- | ------------------------ |
| Time Zone   | Your local zone          |
| Date Format | MM/DD/YYYY or DD/MM/YYYY |
| Currency    | USD, CAD, EUR, etc.      |

## Notifications

**Settings > Notifications**

| Notification     | Email | Push | SMS |
| ---------------- | ----- | ---- | --- |
| New job assigned | Yes   | Yes  | No  |
| Payment received | Yes   | Yes  | No  |
| Invoice overdue  | Yes   | No   | No  |
| Emergency job    | Yes   | Yes  | Yes |

## Job Settings

**Settings > Jobs**

| Setting          | Recommended     |
| ---------------- | --------------- |
| Default Duration | 1 hour          |
| Buffer Time      | 15 minutes      |
| Reminder Timing  | 24 hours before |

### Job Types

Create job types for your services:

- Name, Color, Default Duration, Price

## Invoice Settings

**Settings > Invoices**

| Setting         | Description                        |
| --------------- | ---------------------------------- |
| Prefix          | Invoice number prefix (e.g., INV-) |
| Starting Number | First invoice number               |
| Payment Terms   | Default due date (Net 30)          |
| Auto-Send       | Email invoice on job completion    |

## Team Members

**Settings > Team > + Invite User**

| Role       | Access Level                |
| ---------- | --------------------------- |
| Admin      | Full access                 |
| Manager    | Manage team, jobs, reports  |
| Dispatcher | Schedule and assign jobs    |
| Technician | View/complete assigned jobs |
| Billing    | Invoices and payments only  |

## Integrations

**Settings > Integrations**

| Integration     | Purpose                |
| --------------- | ---------------------- |
| Stripe          | Accept online payments |
| QuickBooks      | Sync invoices          |
| Google Calendar | Calendar sync          |
